# Kill Your Darlings – Curate Your Images

## Objective

This assignment focuses on selecting images intentionally rather than generating as many AI images as possible.

## Decisions

### Real Images

- Professional profile photo
- Portfolio screenshots
- GitHub screenshots
- Project screenshots
- Certificates

These represent real evidence of my work and identity.

### AI Images

Generated only for decorative purposes:

- Hero background
- Abstract AI texture
- Minimal icon set
- Section divider

All AI-generated visuals follow the same visual identity:

- Dark
- Glassmorphism
- Blue gradients
- Minimal geometry
- Soft lighting

## What I Rejected

I rejected AI images that:

- distracted from the content
- introduced unrelated futuristic elements
- broke the colour palette
- looked inconsistent with the Identity Kit

## Key Lesson

AI should enhance presentation, not replace evidence.

Real work deserves real screenshots.

AI is best used for supporting visuals rather than pretending to be proof.
