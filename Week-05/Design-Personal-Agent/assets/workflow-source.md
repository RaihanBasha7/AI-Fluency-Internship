# Workflow Diagram 

## Purpose

This prompt was used to generate the workflow diagram for the **AI Career Copilot** project.

---

# Prompt

Create a professional workflow diagram showing how **AI Career Copilot** processes a user request from input to final response.

---

## Style

- Modern software workflow
- White background
- Blue accent colors
- Flat vector icons
- Enterprise engineering documentation style
- Clean typography
- High resolution
- 16:9 aspect ratio

---

## Title

**AI Career Copilot – Request Processing Workflow**

---

## Workflow

Start

↓

User submits a request

↓

Intent Detection

↓

Understand User Goal

↓

Determine Required Tools

↓

Retrieve Required Context

Sources may include:

- Resume
- GitHub Repository
- Portfolio
- Markdown Notes
- Research Papers
- Job Description
- Web Search

↓

Reasoning & Planning

↓

Generate Response

↓

Safety & Guardrail Validation

Checks include:

- Hallucination Prevention
- Privacy Check
- Confirmation for Sensitive Actions
- Source Verification

↓

Structured Response Generation

↓

Deliver Response to User

↓

End

---

## Example Inputs

Display examples beside the workflow:

- Review my resume
- Explain RAG
- Plan my learning this week
- Review my GitHub repository
- Summarize this research paper

---

## Example Outputs

Display corresponding outputs:

- Resume Review
- Learning Plan
- Technical Explanation
- Repository Feedback
- Research Summary

---

## Visual Elements

Use simple icons for:

- User
- AI Brain
- Database
- GitHub
- PDF
- Browser
- Calendar
- Shield (Safety)
- Checklist
- Documents

Use arrows between each processing stage to illustrate sequential execution.

---

## Design Notes

The workflow should clearly communicate how the AI agent receives a request, reasons about it, retrieves relevant information, validates safety, and returns a structured response.

Avoid unnecessary artistic effects. Prioritize readability and a professional engineering style suitable for software architecture documentation.
