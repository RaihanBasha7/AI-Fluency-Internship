# Workflow vs Agent

## My FL-04 Project

Classification: Workflow

Reason:
The pipeline follows a fixed sequence:

1. Research
2. Generate notes
3. Review
4. Improve
5. Final output

The AI never decides what step comes next.
Every action is predefined.

Therefore it is a workflow rather than an autonomous agent.

## Future Agent Version

The system could become an agent by:

- Deciding when more research is needed
- Searching multiple sources automatically
- Comparing conflicting information
- Choosing better prompts
- Retrying failed steps
- Asking clarification questions
